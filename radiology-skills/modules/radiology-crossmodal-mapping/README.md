# radiology-crossmodal-mapping

**跨模态映射师**：用于设计和审查影像表型、影像 habitat、ROI/VOI 区域与单细胞、空间转录组、病理细胞状态之间的跨尺度映射。

## 它能做什么

- 建立 patient -> lesion -> specimen -> section -> region -> cell 的映射层级。
- 判断数据是直接配对、弱配对、部分配对、未配对还是无法解析。
- 设计影像 habitat 与细胞状态、空间邻域、病理区域之间的对应关系。
- 规划 pseudobulk、去卷积、label transfer、contrastive mapping、graph alignment 等路线。
- 识别空间错位、时间间隔、治疗干预、取样偏倚、尺度不匹配和模型暴露风险。
- 设计负对照、置换检验、敏感性分析、外部验证和正交生物学验证。

## 典型触发

- “我想把 MRI habitat 和单细胞里的免疫细胞状态对应起来。”
- “影像 ROI 和空间转录组区域不是完全一一对应，怎么设计分析？”
- “公共单细胞数据能不能支持我的影像组学机制解释？”
- “帮我判断这套影像-单细胞映射能写到机制支持还是只能写假设生成。”

## 边界

未配对公共组学或参考图谱不能作为患者级、病灶级或局部机制证明。没有可靠空间注册时，只能做患者级或队列级关联，不应写成 co-localization。
