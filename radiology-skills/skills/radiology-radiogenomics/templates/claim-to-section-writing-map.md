# Claim-to-Section Scientific Writing Map

Use this template to turn a locked scientific ledger into a manuscript architecture or a targeted
revision. It is not permission to fill missing results. Preserve `AUTHOR_INPUT_NEEDED` and
`W-RETURN-TO-LEDGER: source required` exactly where the source evidence is unavailable.

## 4. Claim destination map

`Evidence pointer` records where support currently exists. `Target section` and `Destination` record
where the manuscript should communicate it; never combine these fields.

Claim-link status to `proposed`, set Status to `blocked`, and do not treat it as positive evidence.
