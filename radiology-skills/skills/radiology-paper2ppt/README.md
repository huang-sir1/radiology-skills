# radiology-paper2ppt

面向影像科研人员的证据导向演示 skill，覆盖项目标书答辩、组会、学术会议、journal
club、项目复盘、学位答辩和结果汇报。它先按“听众要完成什么判断”选择演示路由，再按
证据成熟度限制标题、图表、影像和口头结论，既可以只输出内容规划，也可以在明确要求时
调用演示文稿工具制作或修订真实 PPTX。

## 关键边界

- 标书科学内容的撰写和审阅属于 `radiology-grant`；本 skill 只将已冻结的标书内容转为
  答辩或路演 deck。
- 独立论文图、表的制作分别属于 `radiology-figure`、`radiology-table`；本 skill 负责其
  在幻灯片中的选择、裁剪、重绘记录和证据语境。
- 内容规划不冒充 PPTX；文件制作不冒充科学验证；渲染、可访问性和计时彩排分别报告。
- 医学影像必须在插入前永久去除 PHI。PowerPoint 内裁剪、黑条遮挡或移出画布不构成
  去标识，公开前还需执行最终包清理和复核。

## 典型触发

- “把冻结后的国自然标书做成 8 分钟答辩 PPT。”
- “明天组会，帮我把中期失败结果组织成能讨论下一步的 deck。”
- “把这篇影像 AI 论文做成中文 journal club，带方法学点评和 speaker notes。”
- “审计这份学位答辩 PPT 的证据链、影像隐私、可访问性和时间。”

实际 PPTX 制作遵循当前可用的 presentation skill/tool；本目录主要维护影像科研演示的
路由、科学内容、来源、隐私和验收契约。
