# Implementation science and scale-up for imaging interventions

Use this reference when the question is not only whether an imaging/AI intervention works, but why,
for whom, in which sites, with what strategy, fidelity, equity and sustainability.

## 1. Select frameworks by job

| Job | Suitable framework | Rule |
|---|---|---|
| determinants/context | CFIR 2.0; NASSS for complex technology adoption/non-adoption/scale/sustainment | select constructs prospectively; do not score every construct by habit |
| outcomes/evaluation | RE-AIM/PRISM and/or Proctor implementation outcomes | separate implementation outcomes from clinical/service outcomes |
| strategies | ERIC taxonomy plus local co-design | link each strategy to an evidenced determinant, mechanism, actor, dose and outcome; no mechanical one-to-one matching |
| effectiveness-implementation balance | hybrid type 1/2/3 | use only when both effectiveness and implementation aims/estimands are real and resourced |
| reporting | StaRI | reporting completeness does not establish design quality or implementation success |

CFIR is a determinant framework, not by itself a step-by-step implementation process. RE-AIM's five
dimensions are Reach, Effectiveness, Adoption, Implementation and Maintenance; PRISM adds multilevel
context. Preserve the chosen framework version, constructs, rationale and adaptations.

## 2. Implementation passport

Freeze:

`intervention release bundle | setting/sites | eligible patients/cases/users | current workflow and
comparator | determinants/barriers/facilitators | implementation strategies and mechanisms | clinical,
service and implementation outcomes | independent units/time | equity | data sources | thresholds |
owners | adaptation/change-control rules | sustainment/de-implementation criteria`.

Common implementation outcomes include acceptability, adoption, appropriateness, feasibility,
fidelity, implementation cost, penetration/reach and sustainability. Define operational numerator,
denominator, timing, source and uncertainty; survey satisfaction alone is not safe/effective use.

## 3. Imaging-specific determinants and strategies

Audit PACS/RIS/EHR/worklist integration, radiologist/technologist/referrer roles, off-hours staffing,
scanner/vendor/protocol mix, false-alert workload, display/uncertainty/abstention, report/critical-result
communication, IT/security/clinical-engineering support, downtime/fallback, reimbursement/resource
capacity and whether an alerted action is actually available.

For each strategy record:

`determinant evidence -> strategy name/definition -> actor/target -> action/dose/timing -> mechanism ->
implementation outcome/criterion -> data source -> fidelity/adaptation -> owner -> stop/replace rule`.

Training, champions or audit/feedback are not universal solutions. If a strategy is chosen only because
it is popular, mark `STRATEGY_RATIONALE_UNSUPPORTED`.

## 4. Hybrid designs and scale

- Type 1 primarily tests clinical effectiveness while observing implementation context.
- Type 2 gives dual emphasis to effectiveness and implementation strategy/outcomes.
- Type 3 primarily tests an implementation strategy while observing the clinical intervention.

Freeze the two estimand families, allocation unit, contamination, sample-size basis and claim ceiling.
A small uncontrolled rollout with interviews is not automatically a hybrid trial.

Before scale-up, compare site readiness, reach/coverage, fidelity/adaptations, effect heterogeneity,
resource/economic consequences, equity, safety, maintenance burden and local authority. Successful
implementation at one academic center does not establish transport or sustainable scale.

## 5. Stop gates and handoffs

Return `framework-role map -> determinant evidence -> strategy specification -> implementation/clinical
outcome matrix -> hybrid/design route -> equity/adaptation ledger -> scale/sustainment/de-implementation
decision -> claim ceiling`.

Stop when the intervention/version or workflow comparator is undefined, a framework is used as a
generic checklist without constructs/estimands, implementation outcomes lack denominators, strategy
selection has no determinant evidence, or clinical benefit is inferred from adoption/fidelity.

Qualitative determinant work → `radiology-qualitative-mixed-methods`; quantitative inference →
`radiology-stats`; economic value → `radiology-health-economics`; delivery execution →
`radiology-research-ops`.
