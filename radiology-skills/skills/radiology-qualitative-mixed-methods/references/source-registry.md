## Currency rule

The registry proves that a source was checked on the access date, not that it remains current later.
For a submission or grant, record the exact target rule and date separately. If a source has been
superseded or the target requires another framework, preserve the historical entry and add the
current applicable source rather than silently replacing the study's original method.
