# Local assay capability profile

This profile records verified local capability so generic design advice does not masquerade as a
laboratory SOP. Do not place credentials, personal data, hazardous procedural detail or unverified
conditions here. Link controlled documents by identifier/version/owner.

Allowed status values:

- `AVAILABLE_AND_VALIDATED`
- `AVAILABLE_NEEDS_PILOT`
- `EXTERNAL_COLLABORATION_REQUIRED`
- `NOT_AVAILABLE`
- `UNKNOWN_AUTHOR_INPUT_NEEDED`
