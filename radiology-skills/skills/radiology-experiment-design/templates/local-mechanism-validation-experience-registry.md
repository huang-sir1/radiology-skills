# Local mechanism-validation experience registry

This registry captures case-level laboratory experience that may inform later planning or review.
It is not a universal evidence base, protocol, success-rate estimate or substitute for current
literature and controlled SOPs. Preserve negative and inconclusive cases as well as successful ones.

Allowed evidence states: `AUTHOR_REPORTED`, `PARTLY_VERIFIED`, `VERIFIED`, `NOT_ASSESSABLE`.

## Interpretation rules

1. One case is an experience record, not a general rule. Do not infer prevalence, expected success,
   optimal conditions or causal truth from the number of entries.
2. Preserve the original model, assay, intervention, unit, controls, decision criterion and evidence
   locator. A lesson detached from these fields must not be routed as advice.
3. Distinguish an assay failure, intervention failure, model-context limitation, evidence against the
   hypothesis and an unresolved failure. Do not relabel all negative outcomes as technical failures.
4. A repair is reusable only when the new project's context falls inside the stated applicable
   boundary and outside the counterexample boundary. Otherwise mark `LOCAL_VALIDATION_REQUIRED`.
5. Author/laboratory confirmation records who verified the interpretation and when; it does not
   upgrade weak evidence into a universal claim.
6. Link controlled SOP identifiers and versions where relevant; do not copy hazardous procedural
   detail, credentials or personal data into this registry.
7. Recheck current literature, reagent/model validity, governance and local capability before using
   an older case. Retire or supersede stale entries without erasing their historical record.

## Advice handoff

When an entry informs a new plan, cite the Case ID and return:

`shared context -> transferable lesson -> non-transferable elements -> required local confirmation ->
alternative if the experience does not apply`.

Never write "our laboratory found X, therefore X is generally best." Use bounded language such as
"Case MVE-___ suggests checking X in this matched context; applicability requires confirmation."
