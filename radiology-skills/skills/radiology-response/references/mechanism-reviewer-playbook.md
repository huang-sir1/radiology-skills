# Mechanism-manuscript reviewer response playbook

Use this for bulk RNA, scRNA/snRNA, spatial transcriptomics, pathology, multi-omics and measured
perturbation manuscripts without an imaging claim. Do not promise radiology validation or
sample-to-image mapping merely to make a response look multimodal.

| Reviewer concern | What must be adjudicated | Honest response path |
|---|---|---|
| Donors versus cells/spots/regions | whether the biological independent unit supports inference | report donor/patient counts and nesting; use pseudobulk or a justified hierarchical model; do not answer with more cells |
| QC, filtering and reference versions | whether the measured object is stable and reproducible | state preanalytics, thresholds, normalization, annotation/reference versions and sensitivity to consequential choices |
| Batch versus condition/composition | whether the contrast is identifiable | show allocation and confounding, composition-aware or balanced analysis, batch sensitivity and changed/unchanged result |
| Cell-state annotation or reference transfer | whether labels are circular or overconfident | show marker/evidence sources, uncertainty, cross-reference validation and unknown/rejected states |
| Differential expression or abundance | whether multiplicity, pairing and nested structure are handled | state estimand, donor-level contrast, model, effect/interval and FDR family; correct pseudoreplication |
| Trajectory, velocity or lineage | whether ordering is being sold as time or cause | expose assumptions and root choice, add sensitivity/lineage/time evidence where available, or bound wording to inferred ordering |
| Spatial domain, niche or communication | whether resolution, segmentation, spatial null and patient replication support the claim | report physical resolution and registration, test spatial nulls/label permutations, retain donor replication and call scores nominated interactions |
| Functional/mechanistic validation | whether association uniquely supports the proposed mechanism | distinguish orthogonal concordance from perturbation; add the minimum discriminating assay or lower the claim |
| Perturbation, rescue and specificity | whether assignment, efficiency, target engagement, off-targets, dose/time, controls and rescue identify the contrast | state each control and quantified result; do not call guide assignment or virtual perturbation causal evidence |
| Data/code/accession | whether another investigator can reconstruct the result | provide repository/accession, metadata/code/environment and restrictions; never invent a deposit or availability date |

For each accepted request, the response states the operation, result, exact manuscript/figure/
supplement location and residual mechanism boundary. If a reviewer asks for an optional future assay,
first decide whether the current claim actually requires it. An optional experiment may be declined or
placed in future work when the existing claim remains defensible.
