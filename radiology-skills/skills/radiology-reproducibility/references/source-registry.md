state are operational project contracts grounded in the sources below; neither is claimed as a
universal external standard.

## Currency rule

Record the exact standard/repository version used by a package. A current landing page accessed
today is not an immutable replay input. If a dependency, standard or external service changes,
preserve the original receipt and issue a new package/run version rather than rewriting history.
